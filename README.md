## ✨ Features
- Three orbit rings: **Skills**, **Projects** and **About**
- Click any planet to open a details panel with tags and links
- **Live Demo** button and a blinking green dot on projects that run online
- Filter buttons: All, Skills, Projects, About
- Hover to slow the orbit, plus a Pause button
- Mouse parallax, animated stars and a pulsing center core
- Works on desktop and mobile, `Esc` closes the panel
